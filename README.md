# 仮名けいこ · 從零學五十音

一個單檔、離線可用的日文五十音學習工具，為**完全零基礎**設計。

## 怎麼用

**手機（推薦）**——開啟 GitHub Pages 之後，用手機瀏覽器打開網址：

- iPhone：Safari 開啟 → 分享鈕 → 「加入主畫面」
- Android：Chrome 開啟 → 選單 → 「安裝應用程式」

裝好之後從主畫面點開，是全螢幕、沒有網址列、**完全離線可用**，跟一般 App 沒兩樣。

**電腦**——Clone 或下載這個 repo，直接用瀏覽器打開 `index.html` 就能用。app 本體就是那一個檔案，沒有相依套件、不用安裝、不用建置。（直接開檔案時瀏覽器不允許註冊 service worker，所以少了離線快取那一層，其他功能都一樣。）

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | app 本體，所有程式碼、樣式、假名資料都在裡面 |
| `manifest.webmanifest` | 讓它可以被「安裝」到主畫面 |
| `sw.js` | service worker，負責離線快取 |
| `icon-*.png`、`apple-touch-icon.png` | 主畫面圖示 |

改了 `index.html` 之後，記得把 `sw.js` 裡的 `CACHE` 版號 +1，否則已安裝的使用者會一直吃到舊的快取。

## 學習者（多帳號）

一台裝置上可以有好幾位學習者，各自一份**完全獨立**的進度——課程、熟練度、連續天數都分開算。點首頁左上角的名字就能切換、新增、改名、刪除。

適合的情況：家裡一支平板兩個人輪流用、或是你想開一個乾淨的帳號重頭練一次。

### 備份與換裝置

進度存在瀏覽器的 localStorage，所以**換手機、清瀏覽器資料、用無痕模式，進度都會不見**。

「切換學習者」面板裡有匯出／匯入：

- **匯出備份檔**下載一個 `.json`，裡面是所有學習者的完整進度
- **匯入備份檔**在另一台裝置上還原（會取代該裝置目前的資料，動作前會再確認一次）

這是目前唯一的跨裝置方式。沒有雲端同步，也沒有伺服器——這個 app 不會把任何資料傳出去。

## 核心流程：先教會，再測驗

不是一上來就丟選擇題。每一課先把 5 個字**教一遍**，學完這 5 個字才測這 5 個字。

**學習卡**（每個字一張）包含：

- 大大的假名，旁邊是同樣大的羅馬拼音
- **漢字來源**——這是重點，見下一節
- 字形聯想（一句話）
- 筆畫數與筆順通則
- 容易搞混的字提醒（あ 會提醒你別跟 お、ぬ、め 混）
- 當場就能描的十字格，淡色範本照著描
- 發音按鈕（裝置有日文語音時才出現）

**課後測驗**只考剛學的那 5 個字，每個字考三種：看假名選讀音、看讀音選假名、看讀音默寫。選擇題的選項也**只從你學過的字裡出**——不會冒出還沒教過的字讓你亂猜。

答不出來可以按「想不起來，給我提示」，會顯示字源聯想而不直接給答案；用過提示的題目會再出現一次。

## 為什麼強調漢字來源

平假名是漢字的**草書**簡化來的，片假名是取漢字的**偏旁**：

| | |
|---|---|
| あ ← 安 | ア ← 阿（左半） |
| か ← 加（左半「力」）| カ ← 加（就是「力」）|
| ろ ← 呂 | ロ ← 呂（上半，就是「口」）|
| ん ← 无 | ニ ← 二（就是「二」，ni＝two）|
| | ハ ← 八（就是「八」）|
| | ミ ← 三（就是「三」，剛好三筆）|

你是中文母語者，已經認得這些漢字了——這是學五十音最大的優勢，比死背有效得多。92 個假名的字源全部寫進去了。

## 課程結構

共 40 課，每課 3–9 個字：

1. 平假名清音（11 課，46 字）
2. 片假名清音（11 課，46 字）
3. 平假名濁音・半濁音（5 課）
4. 片假名濁音・半濁音（5 課）
5. 平假名拗音（4 課）
6. 片假名拗音（4 課）

課程不上鎖，想跳著上也可以，首頁的「繼續學習」會自動指向下一課。濁音那一章開頭會說明「゛」和「゜」的規則——字形完全不用重學；拗音那章會說明小的ゃゅょ怎麼拼。

## 每課單獨測驗

已完成的課，右邊會多一個「**測驗 →**」按鈕，直接進測驗、跳過學習卡，不用為了複習把整課重看一次。左邊那格仍然是「重學」，想從頭看一遍隨時可以。

## 智慧複習

首頁的「智慧複習」不是隨機抽，也不只是抽到期的字，而是按弱項排序：

```
弱項分數 = (最高熟練度 − 目前熟練度) × 2      熟練度越低越弱
         + 錯誤率 × 8                         權重最高
         + 逾期天數（最多算 7 天）             拖越久越該複習
         + (錯過兩次以上 ? 2 : 0)
```

取最弱的 14 個，**再把它們的「混淆同伴」拉進來一起考**——分不清 `シ` 和 `ツ` 的人，只考 `シ` 是看不出他到底分不分得清的，得兩個一起出現才測得出來。

題型也跟著熟練度走：認不得的字先出選擇題，快熟了就逼你打字或默寫。

| 熟練度 | 出的題型 |
|---|---|
| 0–1 | 看假名選讀音 / 看讀音選假名 |
| 2–3 | 看讀音選假名 / 打字 |
| 4+ | 手寫默寫 / 打字 |

## 間隔複習

每個學過的假名各自記錄熟練度（0–6 級）。答對升一級、答錯降兩級，複習間隔隨等級拉長：1 分鐘 → 10 分鐘 → 1 天 → 2 天 → 5 天 → 12 天 → 30 天。有字到期時，首頁會出現「今日複習」。

首頁下方的五十音圖是完整字表，每格都有假名和羅馬拼音，隨時可以當字卡查。顏色越深＝記得越牢，右上角紅點＝今天該複習。

## 干擾選項是刻意挑的

選擇題的錯誤選項不是隨機抽的，優先從「已知會互相搞混的字組」裡挑——出 `ツ` 時選項會有 `シ`、`ソ`、`ン`，出 `テ` 就配 `チ`、`ナ`。答錯時下方也會列出容易混淆的同伴。分不清這幾組是最大的卡點，隨機出題練不到。

`シ / ツ` 和 `ソ / ン` 的分辨方式寫在字源說明裡：**點的位置和尾巴的方向**（シ・ツ 尾巴由下往上挑，ソ・ン 由上往下撇）。

## 進階：自由練習

已經有基礎、想直接大量刷題時，首頁最下方展開「自由練習」：自己選範圍（六個牌組）和題型（認字／打字／反查／手寫），不跟著課程走。打字模式會接受訓令式拼法（`si`、`tu`、`sya`⋯）。

## 資料範圍

清音 46 + 濁音・半濁音 25 + 拗音 33，平假名與片假名各一套，共 208 個項目。`ぢ` 和 `づ` 標示為 `ji (di)` / `zu (du)` 以便和 `じ`、`ず` 區分，打字時兩種拼法都接受。

## 字體選擇

辨識題用**明朝體**顯示假名，因為那是書本和考卷上會看到的樣子；手寫的描摹範本改用**黑體**，字形比較接近手寫的筆畫形狀。這是刻意的區分，不是疏漏。

## 例詞

每個清音假名都配一個真的單字，同時解決兩件事。

**一、讓語音唸得出來。** 單獨一個假名只有 0.2 秒，語音引擎沒有足夠的長度產生語調，唸出來一定又短又機械——這是參數調不掉的，降速只會讓它變成又慢又機械。接一個真的詞（`あ` → `あめ`）就有正常的抑揚頓挫了。按發音鈕會**先唸假名、再唸例詞**。

**二、把假名綁到有意義的東西上。** 孤立的符號比有意義的詞難記。片假名這邊尤其划算，例詞幾乎都是你本來就認得的外來語：`カ` → カメラ、`コ` → コーヒー、`テ` → テレビ、`ラ` → ラーメン。

例詞裡的目標假名會標成藍色，一眼看得出它藏在哪。`を`/`ヲ` 是助詞、不會單獨成詞，所以不給例詞；`ん`/`ン` 不會出現在字首，用 `ほん`／`パン` 這種它在字尾的詞。

## 手寫自動辨識

寫完按「檢查我寫的」，會告訴你寫對沒有。**不用機器學習模型，也不用連網。**

作法是最近鄰比對：範本字形本來就是用裝置的字型即時畫出來的，所以可以把你的筆跡跟**同一組裡每一個假名**的字形都比一次，看哪個最像。流程是筆跡和範本各自畫到畫布 → 抓出墨水外框、等比例縮放置中 → 模糊化讓細筆畫容許位置誤差 → 算雙向覆蓋率的調和平均（少寫筆畫和多寫筆畫都會扣分）。

結果會列出前三名和相似度，目標字標成綠色。所以它不只說「錯了」，而是說**「你寫的比較像 ろ」**——那才是你需要的資訊。筆畫數對不上也會另外提醒，因為那通常代表筆順記錯了。

因為範本是用裝置自己的字型產生的，比對基準永遠跟畫面上看到的描摹範本一致，不會有「範本一套、批改另一套」的問題。

### 準確度（實測）

把 92 個清音的字形做隨機旋轉、縮放、位移後丟進去分類：

| | |
|---|---|
| 第一名就猜中 | 275 / 276（99.6%）|
| 前三名內 | 276 / 276（100%）|

辨別力測試：

| 輸入 | 題目 | 結果 |
|---|---|---|
| 寫 `ろ` | `る` | 判成「ろ」，抓到 |
| 寫 `ツ` | `シ` | 目標排到第 10 名，抓到 |
| 寫 `ク` | `ワ` | 目標排到第 45 名，強烈抓到 |
| 亂畫線條 | — | 分數中位 0.28（正確書寫最低 0.50）|

門檻就是這樣定出來的：`0.42` 以上算寫對，`0.28`～`0.42` 算「形狀對但潦草」仍給過，低於 `0.28` 請重寫。

**這個 99.6% 偏樂觀**，因為測試輸入是完美的字型形狀加變形，不是真的手寫。真實手寫分數會更低，所以判錯時一定會保留「我確定我寫對了」讓你自己覆寫——機器判斷是預設值，不是最終裁決。

## 發音

用瀏覽器內建的語音合成，唸的是裝置本身的日文語音，不需要連網、也沒有音檔要下載。

實作上幾個刻意的選擇：音量固定拉到最大；語音清單裡優先挑**非 compact** 的版本（compact 是 iOS 的低音質壓縮語音，同一個發音人常常兩種都在清單裡）；語速假名 `0.75`、例詞 `0.85`，兩段連續排隊送出，中間不 cancel，自然會有停頓。

語音清單在 iOS 和 Chrome 上是非同步載入的，第一次讀常常是空的，所以會延遲重掃兩次——不然發音按鈕會整組不出現。

學習卡預設**自動發音**，翻到新的字就唸一次；測驗答完也會唸一次，把字形和聲音綁在一起。不想要的話按學習卡上的「自動」關掉。

需要裝置本身裝有日文語音（iOS、Android 大多內建）。完全沒有語音合成功能的瀏覽器上，發音按鈕會整組隱藏，其他功能不受影響。

## 資料儲存

全部進度存在瀏覽器的 localStorage，**不會上傳到任何伺服器**，沒有後端、沒有追蹤、不需要註冊。代價是換裝置不會自動同步，要靠上面說的匯出／匯入。

### 儲存鍵不再帶版號

早期版本用 `kana-keiko-v1`、`kana-keiko-v2`、`kana-keiko-v3` 當鍵，每次改版換一次——**這正是進度會不見的原因**，`v1 → v2` 那次沒寫轉移，資料就留在舊鍵裡再也讀不到。

現在主鍵固定是 `kana-keiko`，而且載入時會掃過所有 `kana-keiko*` 開頭的鍵，把每一份都試著解析（新的多人格式、舊的單人格式都認），挑學過最多字的那份用。寧可多讀幾個鍵，也不要再弄丟任何人的進度。

### 存不住的時候會講

載入時會實際寫一筆再讀回來，確認這個瀏覽器真的存得住。無痕模式或瀏覽器擋掉網站儲存時，首頁會出現紅色警告說明「關掉分頁進度就會消失」，而不是讓你學了半天才發現什麼都沒留下。

學過 15 個字以上、而且超過兩週沒備份，首頁會出現一則提醒和一個匯出按鈕。

## 已知限制

**沒有逐筆的筆順動畫**——那需要每個假名的向量筆畫資料。目前用的是「範本描摹 + 筆畫數即時對照」，配合筆順通則（由上到下、由左到右）在實務上夠用：如果你寫完的筆畫數跟標示的對不上，通常就是筆順記錯了。要確認某個字的精確筆順，還是得查筆順表。

**沒有雲端同步**——跨裝置要手動匯出匯入。真的要自動同步就得有後端和真正的帳號系統，那是另一個層級的工程。
