# かな科学 · 科學學五十音

專為**繁體中文母語者 ＋ 具備基礎日語聽感學習者**打造的行動優先五十音科學記憶網頁。

🌐 **線上公開版**：[https://ellencheng503.github.io/kana-keiko/](https://ellencheng503.github.io/kana-keiko/)

## 核心學習科學設計

1. **三重編碼記憶橋接（Tri-Anchor Dual Coding）**
   - **漢字字源橋接**：平假名源自漢字草書（`安 → あ`、`加 → か`），片假名源自漢字偏旁（`伊 → イ`、`力 → カ`、`口 → ロ`），直接利用中文母語優勢秒記字形。
   - **聽覺單字錨點**：每個假名皆綁定常用日語單字（如 `すし` 壽司、`ねこ` 貓、`コーヒー` 咖啡）並雙段自然發音，將既有的聽說詞彙直接連上視覺字形。
   - **易混淆字防混雷達**：針對 `さ/ち/き`、`は/ほ/ま`、`る/ろ`、`シ/ツ/ソ/ン` 等高頻混淆組提供一秒分辨口訣與專項對決測驗。
2. **3 分鐘微課程閉環（先建檔描紅 ➔ 再多模態提取 ➔ 錯題重測精通）**
3. **離線雙向覆蓋率手寫自動批改**：免連網自動比對筆跡相似度，寫成相似字時即時指出差異。
4. **艾賓浩斯記憶排程與本機自動保存**：每次作答自動寫入瀏覽器 `localStorage`，支援 `.json` 備份匯出與還原。
